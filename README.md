# Excel-Cleaner-and-Formatter-using-Python
This project automates Excel file cleaning using Python. It's useful for freelancers, data entry professionals, and analysts who work with messy Excel files containing missing values, unwanted columns, and inconsistent formatting.
# Features:

1. Removes unnecessary columns like Unnamed: 0
2. Cleans and standardizes column names (e.g. Product Name → product_name)
3. Fills missing values with default values (like 0)
4. Saves a cleaned Excel file
# Files Included:

sample_excel_data.xlsx → Raw Excel file with 100+ rows

excel_cleaner.py → Main Python script

cleaned_output.xlsx → Auto-generated cleaned Excel file (after running script)

README.md → This file
